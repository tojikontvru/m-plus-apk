## Установка

1. Скачайте `MPlus.apk` по ссылке выше.
2. Откройте файл на телефоне.
3. Если Android спросит — разрешите установку из этого источника.
4. Готово: откройте M Plus и нажмите «Обновить».

Подпись приложения не меняется, поэтому новая версия ставится поверх старой.
